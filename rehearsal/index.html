키는 이 기기의 브라우저에만 저장되며 구글 외의 어디로도 전송되지 않습니다.
Chirp 3 HD가 가장 자연스럽습니다. 한 번 합성한 문장은 기기에 보관되어 반복 재생에는 추가 비용이 들지 않습니다.
모든 슬라이드의 대본을 mp3로 합성해 ZIP으로 저장합니다. 이 파일들을 게시된 앱의 녹음 칸에 올리면 휴대폰에서도 같은 음성으로 연습할 수 있습니다.
목록은 품질이 좋은 순으로 정렬되며, 기본값은 가장 자연스러운 음성입니다.

내 발표 자료

올린 파일과 대본, 녹음이 이 기기에 함께 저장됩니다.

구글 클라우드 TTS 연결하기

5분이면 끝납니다. 월 100만 자(강의 대본 약 100벌)까지 무료입니다.

console.cloud.google.com 에 구글 계정으로 접속해 새 프로젝트를 만듭니다.
검색창에 Cloud Text-to-Speech API 를 입력하고 사용 버튼을 누릅니다.
무료 한도 안에서만 쓰더라도 카드 등록이 필요합니다. 한도를 넘지 않으면 청구되지 않으며, 결제 페이지에서 예산 알림을 걸어 두면 안전합니다.
API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키 순서로 누르면 AIza… 로 시작하는 키가 나옵니다.
만든 키를 눌러 API 제한사항 → 키 제한 에서 Cloud Text-to-Speech API 만 선택해 저장하세요. 키가 새어 나가도 다른 서비스에는 쓰이지 못합니다.
설정 화면의 구글 API 키 칸에 붙여넣고 연결 확인을 누르면 음성 목록이 채워집니다.
이 파일을 브라우저에서 직접 열었을 때 연결이 막히는 경우가 드물게 있습니다. 그럴 때는 파일이 있는 폴더에서 python3 -m http.server 8000 을 실행하고 localhost:8000 으로 여시면 됩니다.

사용법

PPT 발표를 영어·한글 이중 대본으로 연습하는 도구입니다.

올린 자료는 자료실에 쌓입니다. 발표 자료를 여러 개 저장해 두고 필요할 때 열기로 바꿔 가며 연습할 수 있습니다. 개수 제한은 없으며 이름 바꾸기와 삭제도 그 화면에서 합니다.
.pptx를 그대로 올리면 슬라이드를 그려 보여 주고, 발표자 노트에 적어 둔 대본을 자동으로 가져옵니다. 레이아웃이 원본과 다르게 보이면 PPT를 PDF 또는 이미지로 내보내 올리시면 원본 그대로 표시됩니다.
발표자 노트에 영어 대본을 쓰고 --- 한 줄을 넣은 뒤 한글 대본을 적으면 위·아래 칸으로 나뉩니다. 구분선이 없으면 한글이 섞인 문단을 자동으로 구별합니다.
기본은 기기 내장 음성(TTS)이며 영국식·미국식을 고를 수 있습니다. 설정에서 음성은 품질 좋은 순으로 정렬되니 미리 듣기로 비교해 고르세요. 신경망(Natural·Premium) 음성이 원어민에 가장 가깝습니다. 더 좋은 음성이 필요하면 내려받은 독립 실행 파일에서 구글 클라우드 TTS를 연결할 수 있습니다. 직접 녹음한 파일을 쓰려면 대본 칸의 녹음 버튼으로 오디오를 올리세요. 그 슬라이드는 녹음본이 우선 재생됩니다. 반복은 최대 3회입니다.
슬라이드를 클릭하면 다음 장으로 넘어갑니다. 아래에서 고정 시간 또는 낭독 후를 고른 뒤 슬라이드 아래 자동 버튼을 누르면 자동으로 넘어갑니다. 특정 장만 시간을 다르게 주려면 초를 입력하고 이 장만을 누르세요.
